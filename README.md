## 📌 Proje Hakkında

Kanyon'da 18-19-20 Eylül 2026'da düzenlenen Türkiye'nin en büyük sağlıklı yaşam festivali için hazırladığım etkinlik sitesi. Sürüklenebilir program kartları, kendi programını oluşturup takvime aktarma, konuşmacı kartları, interaktif festival haritası ve ücretsiz kayıt içeriyor.
